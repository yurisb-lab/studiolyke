# Fatiador L.Y.K.E 3D

App web da L.Y.K.E 3D para dividir, conectar, pintar, texturizar e fotografar peças 3D e exportar 3MF pronto para o Bambu Studio (Bambu Lab A1 + AMS).

- Abrir o app: pelo GitHub Pages deste repositório.
- Plano completo: [`docs/PLANO.md`](docs/PLANO.md)
- Regras do projeto: [`CLAUDE.md`](CLAUDE.md)
- Mudanças de cada versão: [`CHANGELOG.md`](CHANGELOG.md)
- Bibliotecas e licenças: [`LICENSES.md`](LICENSES.md)

Tudo roda no navegador: os arquivos nunca saem do aparelho. Sem etapa de build: HTML, CSS e JavaScript puro, com bibliotecas pelo CDN em versão fixa.

## Testes automáticos (só para quem desenvolve)

```
npm install
npm test
```

O Node e o npm são usados **só nos testes**. Veja [`testes/README.md`](testes/README.md).
